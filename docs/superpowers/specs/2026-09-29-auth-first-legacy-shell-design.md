# 인증 우선 OH 화면 복원 설계

## 목표

Supabase의 실제 회원·요청·배정·출고 데이터를 유지하면서, 기존 OH 화면의 좌측 사이드바·상단 헤더·카드·테이블 중심 레이아웃을 복원한다.

## 동작

- `/`은 항상 `/login`으로 이동한다.
- 로그인 성공 시 프로필 역할에 따라 `/admin` 또는 `/user`로 이동한다.
- 로그아웃은 Supabase 세션을 종료하고 `/login`으로 이동한다.
- 로그인하지 않은 사용자는 업무 화면에 접근할 수 없다.

## 화면

- 공통 셸: 짙은색 좌측 사이드바, 상단 헤더, 로그아웃 버튼.
- 관리자: `대시보드`, `OH 요청`, `OH 배정`, `재고`, `출고 현황` 메뉴. 대시보드는 실제 요청·배정·출고·매출 집계를 카드로 표시한다.
- 사용자: `OH 등록`, `OH 요청 현황`, `배정 및 출고 현황` 메뉴 순서를 유지한다.
- 기존 역할 선택, 가상 데이터, localStorage 저장은 복원하지 않는다.

## 검증

- 루트는 항상 로그인으로 이동한다.
- 로그인 성공은 올바른 역할 화면으로 이동한다.
- 로그아웃은 세션을 지우고 로그인 화면으로 이동한다.
- 관리자와 사용자 메뉴·데이터 경계는 기존 Supabase RLS 정책을 그대로 사용한다.
