# 사용자 준비 체크리스트

## 1. 영업 요청 샘플

파일명: `input-samples/sales-request-anonymized.xlsx`

실제 신청서의 시트 이름과 열 제목은 그대로 두고, 행 데이터만 익명화합니다. 가능하면 아래 상황이 포함된 10~20행을 준비합니다.

- 한 요청에서 수량이 1대인 경우
- 한 요청에서 같은 기종을 여러 대 신청한 경우
- 서로 다른 팀이 같은 기종을 신청한 경우
- 파트너사가 있는 요청과 없는 요청
- 희망 출고일이 있는 요청과 없는 요청
- 비고가 있는 요청
- 취소되었거나 변경된 요청이 있다면 해당 형태

익명화 예시는 다음과 같습니다.

| 실제 값 종류 | 가상 값 예시 |
|---|---|
| 파트너사 | 파트너A, 파트너B |
| 영업사원 | 영업사원01, 영업사원02 |
| 이메일 | salesperson01@example.com |
| 전화번호 | 010-0000-0001 |
| 기종 | MODEL-A, MODEL-B |
| 금액 | 1,000,000 / 2,000,000 |

열이 존재한다면 유지할 항목은 신청일, 부, 팀, 영업사원, 이메일, 파트너사, 요청 기종, 수량, 희망 출고일, 단가 또는 예상 매출, 비고입니다. 없는 열을 새로 만들 필요는 없습니다.

## 2. OH 재고 샘플

파일명: `input-samples/inventory-anonymized.xlsx`

아래 정보가 있는 10~20행을 준비합니다.

- 기종
- 가상 SN
- 생산 완료일 또는 입고일
- 현재 상태
- 별도로 관리하는 비고

상태 값은 실제 파일에서 사용하는 표현을 유지합니다. 예를 들어 `재고`, `배정`, `출고`, `수리`처럼 사용 중이라면 그 값을 그대로 사용합니다.

## 3. 조직 및 파트너 기준 샘플

파일명: `input-samples/organization-anonymized.xlsx`

가능하면 다음 열을 준비합니다.

- 부
- 팀
- 영업사원
- 이메일
- 사용 여부
- 담당 파트너사

파트너사와 영업사원의 관계가 한 명 대 여러 회사라면 한 행에 하나의 관계가 보이도록 작성합니다.

## 4. 익명화 확인

폴더에 넣기 전에 아래 항목을 다시 확인합니다.

- 실제 회사명과 파트너사명이 없음
- 실제 사람 이름과 사번이 없음
- 실제 이메일과 전화번호가 없음
- 실제 장비 SN가 없음
- 실제 계약번호와 주문번호가 없음
- 민감한 비고와 내부 메모가 없음
- 실제 매출을 그대로 사용하지 않음
- 숨겨진 시트, 메모, 셀 주석에도 실제 정보가 없음

## 5. GitHub와 Vercel 준비

아직 저장소나 프로젝트를 직접 만들 필요는 없습니다. 구현을 시작할 때 다음만 준비되어 있으면 됩니다.

- 개인 또는 회사에서 허용한 GitHub 계정
- GitHub 2단계 인증 설정
- Vercel 계정
- Vercel에서 GitHub 연결이 가능한지 확인

GitHub 저장소는 비공개로 만들고, Vercel은 데모 데이터만 사용하도록 설정합니다.
